RX-CW

Entraîneur de morse (CW) en ligne, gratuit et accessible directement dans le navigateur — aucune installation requise.

Description

RX-CW est un outil web d'entraînement à la copie et à la manipulation en morse, pensé pour les radioamateurs francophones. Il tient dans une seule page HTML autonome, à ouvrir directement dans n'importe quel navigateur (ordinateur, tablette, mobile), sans serveur ni dépendance externe. Il propose :

Mode QSO en français : simulation d'un contact radio complet
Notation de session : suivi de la progression et des erreurs
Simulation de QRM et bruit de bande : pour s'entraîner dans des conditions proches du réel
Compteur de répétitions (RPT) : déclenchable via le manipulateur (paddle) en mode transmission
Rejeu de session : possibilité de réécouter l'historique complet d'une session en mode guidé
Utilisation
Télécharge le fichier .html de ce dépôt
Ouvre-le avec n'importe quel navigateur (double-clic suffit)
Choisis le mode d'exercice souhaité
Règle la vitesse et les options d'entraînement selon ton niveau
Lance la session

Aucune inscription ni installation n'est nécessaire — tout fonctionne en local, directement dans le navigateur.

RX-CW (English)

A free, browser-based CW (Morse code) training tool — no installation required.

Description

RX-CW is a web-based Morse code copying and sending trainer, designed with French-speaking radio amateurs in mind. It's a single, self-contained HTML page you can open directly in any browser (desktop, tablet, mobile), with no server or external dependency. It offers:

French QSO mode: simulates a complete radio contact
Session scoring: tracks progress and mistakes
QRM and band noise simulation: practice under near-real conditions
Repeat counter (RPT): triggerable via the paddle in sending mode
Session replay: replay the full history of a session in guided mode
Usage
Download the .html file from this repository
Open it in any browser (just double-click it)
Choose the exercise mode you want
Adjust speed and training options to your level
Start the session

No sign-up or installation required — everything runs locally, right in your browser.
